MacでPDFの読み上げエビデンスを作る方法

プレビュー.app＋VoiceOverを使ったテキスト保存手順

この手順書は iPDFオフィシャルの推奨例ではありません。Macで作業する方向けに考えた方法です。

この方法でできること

プレビュー.app上でVoiceOverが取得した内容を保存します

  • PDFをプレビュー.appで開きます。
  • VoiceOverカーソルで内容を順番に確認します。
  • VoiceOverが取得した読み上げ文字列を保存します。
  • evidence.txtと、確認用のraw.logを作成します。
  • PDF本文の直接抽出やOCRではありません。

用意するもの

  • macOS搭載Mac
  • プレビュー.app（macOS標準機能）
  • VoiceOver（macOS標準機能）
  • ターミナル.app（macOS標準機能）
  • run_voiceover_evidence.sh（本ツール）
  • 読み上げ確認を行うPDF

初回だけ必要なMacの権限

初めて実行するときは、ターミナル.appに次の2種類の許可が必要です。

1　アクセシビリティを許可する

初回実行の前に、利用者が実行に使うターミナル.app へアクセシビリティの許可を与えてください。

設定場所

システム設定
→ プライバシーとセキュリティ
→ アクセシビリティ
→ ターミナル.app を許可

この権限画面を本ツールが自動操作することはありません。利用者が設定画面で確認してください。

2　オートメーションを許可する

ターミナル.appから初めてツールを実行すると、次の許可画面が表示される場合があります。

  • “ターミナル.app”が“プレビュー.app”を制御するアクセス
  • “ターミナル.app”が“System Events.app”を制御するアクセス

どちらも「許可」を選んでください。

  • プレビュー.app：対象PDFを開き、表示中の文書とページを確認するため
  • System Events.app：VoiceOverユーティリティなどの画面上の項目を確認するため

注意：許可画面で停止した場合

本ツールは許可画面を自動操作しません。

許可画面で停止した場合は、必要な許可を行ったあと、同じコマンドをもう一度実行してください。

「許可しない」を選んだ場合

システム設定
→ プライバシーとセキュリティ
→ オートメーション
→ ターミナル.app

その配下にあるプレビュー.appとSystem Events.appを許可してください。

VoiceOver Utilityの設定

実行前に、VoiceOver Utilityで次の3点を確認してください。ツールはこれらの設定を自動変更しません。

一般

AppleScriptによるVoiceOverの制御を許可

ON

ナビゲーション

グループ化の動作

グループを無視

詳細度 → ヒント

VoiceOverカーソル内の項目の使いかたを読み上げる

OFF

実行前にVoiceOverユーティリティの「ナビゲーション」を開いたままにしておく必要はありません。ツールが設定確認のため自動的に「ナビゲーション」を表示します。

ツールは「グループ化の動作」の現在値を確認しますが、設定値は変更しません。

実行後は「ナビゲーション」が表示された状態になることがあります。

ヒントをOFFにするのは、PDF本文や画像説明に続く操作案内が、保存する読み上げ文字列へ混ざることを防ぐためです。

ツールとPDFの置き方

はじめて使う場合は、ツールとPDFを同じ作業用フォルダに置くと分かりやすくなります。

作業用フォルダ/
├── run_voiceover_evidence.sh　（本ツール）
└── 確認するPDF.pdf

PDFは同じフォルダに置かなくても構いません。PDFをツール基準の相対パス、または絶対パスで指定できます。

実行方法

1

ターミナル.appを開きます。

2

ツールがあるフォルダへ移動します。

3

VoiceOverをオンにします（Command＋F5を押します）。

4

PDFを指定して実行します。

5

実行が終わるまでMacを操作しないでください。

6

output内の結果を確認します。

実行前チェック

  • プレビュー.appは、前回表示していたページから開く場合があります。実行前に対象PDFを1ページ目で表示し、その状態で閉じてください。

ターミナル.app では以下のように入力して実行してください。

cd "/ツールがあるフォルダ"

./run_voiceover_evidence.sh "確認するPDF.pdf"

パスをドラッグして指定する方法

パスを入力する代わりに、Finderからドラッグで指定できます。

  1. ターミナル.appで、次のところまで入力します。
cd （スペースを1つ入れてください）
  1. Finderで作業フォルダのある場所を開きます。
  2. 作業フォルダをターミナル.appへドラッグします。
  3. 作業フォルダのパスが自動入力されたことを確認し、Enterを押します。
  4. 作業フォルダに移動できましたので、以下のコマンドで実行できます。
./run_voiceover_evidence.sh "PDFファイル名"

空白や日本語を含むパスでも、ドラッグ操作で指定できます。

実行中の注意

  • VoiceOverをオフにしないでください。
  • キーボードやマウスを操作しないでください。
  • プレビュー.appや別アプリへ切り替えないでください。
  • 実行中に対象PDFを閉じないでください。
  • ツールが終了し、ターミナル.appの入力待ちへ戻るまで待ってください。

保存されるファイル

output/
└── PDFファイル名_実行日時/
    ├── evidence.txt
    └── raw.log

evidence.txt

VoiceOverが取得した読み上げ文字列の書かれたエビデンスファイルです。
手作業で書き換えず、そのまま保存してください。

raw.log

実行条件や終了状態を確認するための記録です。通常は編集せず、そのまま保管します。

正常終了の確認

実行が終わったら、ターミナル.appの末尾で次の2行を確認します。

保存先として、直前に次の2行も表示されます。

EVIDENCE_OUTPUT: output/.../evidence.txt
RAW_LOG_OUTPUT: output/.../raw.log
EOF_DETECTED: YES
EXIT_STATUS: 0

この表示は、PDFの最後まで確認し、正常に終了したことを示します。

それ以外の場合は、evidence.txtを正式な結果として扱う前に原因を確認してください。

evidence.txtで確認すること

  • 読み上げ順が意図した順序になっている
  • 本文が抜けていない
  • 画像説明が含まれている
  • 不要な操作案内が混ざっていない
  • 最終ページまで含まれている
  • 同じ本文が不自然に重複していない

Page 2 Page 2のような発話も、勝手に削除しないでください。

VoiceOverが返した文字列は、不要に見える場合でも無加工で保存する方針です。

テキストエビデンスの範囲

  • evidence.txtはVoiceOverが取得した読み上げ文字列です。
  • PDF本文のコピー、OCR、目視での転記ではありません。
  • 音声ファイルではありません。
  • アクセントや漢字の読み方まではTXTから判断できません。
  • 発音確認が必要な場合は、実際のVoiceOver音声を別途聞いて確認してください。

表を含むPDFについて

本ツールは、表の存在を「表」として取得しますが、表の中にあるセルの内容は自動取得しません。表の内容は、VoiceOverで表の中へ入り、別途確認してください。

うまく動かないとき

まず、ターミナル.appの最後に表示された2行を確認してください。

EOF_DETECTED: YES
EXIT_STATUS: 0

この組み合わせでない場合は、該当する症状を開いて確認してください。詳しい停止理由はraw.logに記録されます。

症状：権限に関する表示で停止した

考えられる原因

  • ツールを実行したターミナル.appにアクセシビリティ権限がない
  • プレビュー.appまたはSystem Events.appのオートメーション許可がない

対処方法

  • システム設定の「アクセシビリティ」を確認する
  • システム設定の「オートメーション」を確認する
  • 許可後に同じコマンドを再実行する
症状：VoiceOverの設定確認で停止した

考えられる原因

  • VoiceOverがオンになっていない
  • 「AppleScriptによるVoiceOverの制御を許可」がオフ
  • 「グループ化の動作」が「グループを無視」になっていない

対処方法

  • VoiceOverをオンにする
  • VoiceOver Utilityの3つの設定を確認する
  • 設定確認後にもう一度実行する
症状：PDFが見つからない、または開かない

考えられる原因

  • PDFのファイル名またはパスが違う
  • 空白や日本語を含むパスの指定が正しくない
  • PDFが移動または削除されている

対処方法

  • パス全体を引用符で囲む
  • FinderからフォルダまたはPDFをターミナル.appへドラッグして指定する
  • Finderで対象PDFが存在することを確認する
症状：1ページ目ではないため停止した

考えられる原因

  • プレビュー.appが前回表示していたページを記憶している
  • 対象PDFが2ページ目以降で開いた

対処方法

  • 対象PDFをプレビュー.appで開く
  • 1ページ目を表示する
  • その状態でPDFを閉じる
  • ツールをもう一度実行する
症状：evidence.txtが途中で終わっている

考えられる原因

  • 実行中にMacを操作した
  • 別のアプリへ切り替えた
  • VoiceOverを途中でオフにした
  • PDFの最後へ到達する前にツールが停止した

対処方法

  • raw.logのEOF_DETECTEDとEXIT_STATUSを確認する
  • raw.logの停止理由を確認する
  • VoiceOverをオンにして、実行中はMacを操作せず再実行する
症状：evidence.txtに操作案内が混ざった

考えられる原因

  • VoiceOver Utilityの「VoiceOverカーソル内の項目の使いかたを読み上げる」がオンになっている

この設定がオンの場合でも、ツール自体は正常終了する可能性があります。

対処方法

  • VoiceOver Utilityの「詳細度 → ヒント」を開く
  • 「VoiceOverカーソル内の項目の使いかたを読み上げる」をオフにする
  • ツールを再実行する
症状：「permission denied」と表示された

考えられる原因

  • run_voiceover_evidence.shに実行権限が付いていない

対処方法

chmod +x run_voiceover_evidence.sh

このコマンドは必要な場合だけ実行してください。

参考：Pagesから読み上げ可能なPDFを作る方法

  • PagesのPDF書き出しでアクセシビリティを有効にします。
  • 画像の設定で「説明」にaltテキストを入力してください。
  • 「説明」がPDFのaltテキストとしてVoiceOverへ伝わります。
  • 読み上げ順はPages内部のテキストエリアやオブジェクト構造に影響されます。
  • 見た目が上から下でも、読み上げ順が同じとは限りません。
  • テキスト枠やオブジェクトを作成した順番に影響されます。
  • PDF書き出し後に、必ずVoiceOverで順序を確認します。
  • 固定配置の絵本でも読み上げ可能なPDFを作成できます。
  • リガチャによってPDF内の文字取得へ影響が出る場合があります。文字の欠落や結合があれば、リガチャ設定を確認してください。
  • ページ番号を設定すると、順番どおりに読み上げない場合があります。

動作環境

Apple M2搭載Mac・MacOS Tahoe26.6.2
でのみ動作確認をしております。

Apple M2搭載Mac固有の機能は使用しておりませんが、MacOSのバージョンによってOS標準機能が変わる可能性があり、動作に影響する場合があります。
