# MacでPDFの読み上げエビデンスを作るツール

macOSの「プレビュー」とVoiceOverを使い、PDFからVoiceOverが取得した文字列をテキストファイルへ保存するツールです。

このツールおよび手順は、iPDF公式の推奨例ではありません。また、Appleの製品ではありません。

## 動作環境

- macOS（日本語環境）
- プレビュー
- VoiceOver

Apple M2搭載Mac、macOS Tahoe 26.6.2で動作を確認しています。ほかの環境での動作は保証していません。

## 内容

- `run_voiceover_evidence.sh`：PDFを確認し、結果を保存するツール
- `MacでPDFの読み上げエビデンスを作る方法_2026-09-05.html`：準備と操作方法を説明するマニュアル
- `sample/`：動作確認用のPDFと出力例
- `LICENSE`：本ツールのライセンス

## 使い方

最初に[HTMLマニュアル]((https://corriedale99.github.io/mac-voiceover-pdf-evidence/MacでPDFの読み上げエビデンスを作る方法_2026-09-05.html))をお読みください。

```shell
./run_voiceover_evidence.sh "確認するPDF.pdf"
```

実行すると、主に次のファイルが作成されます。

- `evidence.txt`：VoiceOverが取得した文字列
- `raw.log`：確認用の記録

## 確認できること・できないこと

- `evidence.txt`は、VoiceOverが取得した読み上げ文字列です。PDF本文のコピー、OCR、目視による転記ではありません。
- 音声ファイルではないため、アクセントや漢字の読み方までは確認できません。
- 表の存在は「表」として取得しますが、表のセル内容は自動取得しません。詳しくはHTMLマニュアルをご確認ください。
- PDF/UAへの適合を判定するものではありません。
- 読み上げ順序や内容は、必要に応じて実際のVoiceOver操作でも確認してください。
